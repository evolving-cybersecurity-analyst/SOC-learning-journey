# WannaCry Enterprise Tactics & Techniques - Summary Table


| Tactic | Technique | What WannaCry does | SOC watches for |
|--------|-----------|--------------------|-----------------|
| **Execution** | Windows Management Instrumentation | Deleting shadow copies to remove amdministrator's ability to restore files. | Execution of `wmic.exe` with suspicious switches. |
| **Persistence** | Windows Service | Creates the service `mssecsvc2.0` with the display name `Microsoft Security Center (2.0) Service` that auto-starts on boot, keeping malware alive. | Service creation events with suspicious names or temp paths. |
| **Privilege Escalation** | Windows Service | Use the same service created for persistence, running with SYSTEM privileges to gain full system access. | Service running as SYSTEM; unexpected elevated privileges on suspicious process. |
| **Stealth** | Hidden Files and Directories | Uses `attrib.exe +h` to mark its files as hidden so they don't appear in normal file browsing. | Abusing of `attrib.exe` command; hidden files in unexpected system locations. |
| **Defense Impairment** | Windows Permissions | Uses `attrib.exe +h` and `icacls.exe` to make some of its file hidden and to remove user's or administrator's ability to access their own files. | Suspicious changes to file permissions on multiple files; abuse of `icacls.exe`. |
| **Discovery** | 1- File and Directory Discovery<br>2- Peripheral Device Discovery<br>3- Remote System Discovery<br>4- System Network Configuration Discovery | 1- Searches various file by extension.<br>2- Automatically detects newly connected USB drives and encrypts all files on them.<br>3- Scan its local Network segment for remote system to exploit and copy itself to.<br>4- Gathers network segment and configuration details to map the network. | 1- Execution of file enumeration commands(e.g. `dir.exe`, `explorer.exe`) and directory discovery activity. Detection of discovery command executed by unexpeted or suspicious user accounts, or originating from unusual source IPs.<br>2- Suspicious enumeration of peripheral attached drives. Detection of WMI process execution for periodic device scanning and file access on newly connected drives.<br>3- Detection of execution of network enumeration commands (`net.exe`, `ping.exe`, etc.) in rapid succession from a single process to discover remote systems in the local network segment.<br>4- Detection of execution of network discovery commands(`ipconfig.exe`, `route.exe`, `nestat.exe`) in rapid succession from a single process. |
| **Lateral Movement** | 1- Exploitation of Remote Services<br>2- Lateral Tool Transfer<br>3- RDP Hijacking | 1- Exploits SMBv1 vulnerability to propagate to connected systems within the network.<br>2- After gaining access via an SMB exploit, copies itself to remote PCs via SMB administrative shares (`C$`, `IPC$`).<br>3- Enumerate remote desktop sessions and execute the malware within those sessions using native Windows commands to maintain high-privilege execution context. | 1- Detection of unusual network traffic to port 445 in rapid succession; failed authentication attempts followed by remote process creation events.<br>2- Detection of file writes to administrative network shares; unusual SMB traffic copying executable files; malware detected on administrative share locations.<br>3- Detection of enumeration of RDP sessions; suspicious execution of `tscon.exe` or session reassignment commands; RDP activity without corresponding authentication events. |
| **Command and Control** | 1- Asymmetric Cryptography<br>2- Multi-Hop Proxy | 1- Use custom cryptographic protocol over Tor for command and control.<br>2- Use Tor Network to mask the source of command and control traffic. | 1- Detection of encrypted outbound traffic to .onion address, without standard TLS handshake; regular communication pattern from the infected host.<br>2- Detection of traffic through Tor exit node; SOCKS proxy usage (port 9050); encrypted traffic patterns consistent with Tor usage, indicative of multi-hop proxy infrastructure. |
| **Impact** | 1- Data Encypted for Impact<br>2- Inhibit System Recovery<br>3- Service Stop | 1- Encrypts user files and demands to be paid to decrypt those files.<br>2- Uses `wmic.exe`, `wbadmin.exe`, `bcdedit.exe`, `vssadmin.exe` to disable system recovery tools.<br>3- Kill processes associated with sensitive data such as `MySQL`, `Exchange`, etc.' to encrypt their data stores. | 1- Detection of high frequency file write operations followed by replacing files with encrypted variants.<br>2- Detection of rapid successions of processes `wmic.exe`, etc.' to delete/disable recovery or backup.<br>3- Detection of elevated execution of commands to stop/disable critical services followed by rapid file encryption activity. |
